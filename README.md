# Anity Corubtion paperless PK school

ระบบใบงานออนไลน์ (Paperless) รายวิชาต้านทุจริต โรงเรียนภูเขียว
เว็บไซต์แบบ Static (HTML/CSS/JavaScript) สำหรับโฮสต์บน GitHub Pages และใช้ Supabase เป็นฐานข้อมูล

## โครงสร้างไฟล์

```
index.html                  หน้าเว็บหลัก (มี favicon จากโลโก้ Google Drive)
css/style.css               ธีม ขาว - ม่วง - ทอง รองรับทุกขนาดหน้าจอ
js/config.js                ตั้งค่าชื่อเว็บ, Supabase URL, API Key, Logo ID
js/*.js                     โค้ดหน้าเข้าสู่ระบบ / นักเรียน / ครู / Admin
assets/logo.png             โลโก้สำรอง
supabase/01_schema.sql      สร้างตาราง คอลัมน์ ฟังก์ชัน และสิทธิ์ทั้งหมด (รันก่อน)
supabase/02_sample_data.sql ข้อมูลตัวอย่าง (ไม่บังคับ)
supabase/03_check.sql       ตรวจสอบปัญหา "นักเรียนส่งแล้วแต่ครูไม่เห็น" (อ่านอย่างเดียว)
```

## ขั้นตอนที่ 1 สร้างฐานข้อมูล

1. เข้า Supabase โปรเจกต์ `uscyhrdjtczrojmgnyiv` แล้วไปที่ **SQL Editor > New query**
2. คัดลอกเนื้อหาทั้งหมดของ `supabase/01_schema.sql` ไปวาง แล้วกด **Run**
3. (ไม่บังคับ) รัน `supabase/02_sample_data.sql` เพื่อเพิ่มนักเรียน ครู และใบงานตัวอย่าง

ตารางที่สร้าง (ทุกตารางมีคอลัมน์ `id` สำหรับอ้างอิง)

| ตาราง | หน้าที่ |
|---|---|
| `data` | รายชื่อนักเรียนต้นทาง: `ID`, `no`, `name`, `class` |
| `userstudent` | บัญชีนักเรียนที่ลงทะเบียน: `ID`, `name`, `class`, `tel`, `password` |
| `userteacher` | บัญชีครู: `username`, `password`, `name`, `class` |
| `admin` | บัญชีผู้ดูแล: `username`, `password`, `name`, `position` |
| `units` / `worksheets` / `questions` | หน่วยการเรียนรู้ ใบงาน (คอลัมน์ `classes` = ห้องที่ทำได้) และข้อคำถาม |
| `submissions` | คำตอบ สถานะ และคะแนนของนักเรียน |
| `reset_attempts` / `app_sessions` | บันทึกการลองรีเซ็ตรหัสผ่าน และการเข้าสู่ระบบ |

ความปลอดภัย: เปิด RLS ทุกตาราง (ไม่มีใครอ่านตารางตรง ๆ ได้ด้วย API Key สาธารณะ) เว็บเรียกผ่านฟังก์ชัน RPC เท่านั้น และรหัสผ่านถูกเข้ารหัสด้วย bcrypt

บัญชีเริ่มต้น
- Admin: `admin` / `Admin@1234` (กรุณาเปลี่ยนรหัสผ่านทันทีในเมนู บัญชีผู้ใช้ > ผู้ดูแลระบบ)
- ครูตัวอย่าง (จากไฟล์ 02): `teacher1` / `Teacher@1234` รับผิดชอบ ม.1/1,ม.1/2
- ครู 1 คนรับผิดชอบหลายห้องได้ โดยคั่นด้วยเครื่องหมายจุลภาค เช่น `ม.1/1,ม.1/2`

## ขั้นตอนที่ 2 การลงทะเบียนและลืมรหัสผ่าน (ไม่ใช้ OTP)

ระบบไม่ใช้ SMS หรืออีเมล จึงไม่มีค่าใช้จ่าย และไม่ต้องติดตั้ง Edge Function

- ลงทะเบียน: กรอกรหัสนักเรียน 5 หลัก ระบบดึงเลขที่ ชื่อ-สกุล และระดับชั้นจากตาราง `data` ให้อัตโนมัติ จากนั้นกรอกเบอร์โทร (###-###-####) แล้วตั้งรหัสผ่านเองได้ทันที
- ลืมรหัสผ่าน: ต้องกรอกเบอร์โทรเดิมที่เคยลงทะเบียนไว้เท่านั้น จึงจะตั้งรหัสผ่านใหม่ได้
- ถ้ากรอกเบอร์ผิดครบ 5 ครั้ง ระบบจะล็อกการรีเซ็ตของรหัสนั้น 15 นาที (ป้องกันการเดาเบอร์)
- กรณีนักเรียนจำเบอร์ไม่ได้ Admin รีเซ็ตรหัสผ่านให้ได้ที่เมนู บัญชีผู้ใช้ > นักเรียน > แก้ไข

อัปเดตจากเวอร์ชันเดิมที่ใช้ OTP: รัน `supabase/01_schema.sql` ซ้ำได้อย่างปลอดภัย ข้อมูลเดิมยังอยู่ครบ ระบบจะลบตาราง/ฟังก์ชัน OTP ออกให้เอง และลบ Edge Function `send-otp` ใน Supabase ทิ้งได้

## การกำหนดระดับชั้นของใบงาน

ในหน้าแก้ไขใบงาน (Admin > จัดการใบงาน > แก้ไข) มีส่วน **ระดับชั้น / ห้องที่ทำใบงานนี้ได้**

- 1 ใบงานเลือกได้หลายห้อง จัดกลุ่มตามระดับชั้น (เช่น ม.1) กด “เลือกทั้งระดับ” “เลือกทั้งหมด” หรือ “ล้าง” ได้
- รายชื่อห้องดึงจากข้อมูลนักเรียน ถ้าห้องที่ต้องการยังไม่มีในรายการ พิมพ์เพิ่มเองได้
- ต้องเลือกอย่างน้อย 1 ห้องจึงจะบันทึกได้
- นักเรียนจะเห็นและทำได้เฉพาะใบงานของห้องตัวเอง ระบบตรวจสอบที่ฐานข้อมูลด้วย และตารางคะแนนของครูจะแสดงเฉพาะใบงานของห้องนั้น
- ใบงานเก่าที่ยังไม่ได้กำหนดห้อง (แสดงป้าย “ทุกห้อง”) จะแสดงให้ทุกห้องจนกว่าจะเข้าไปกำหนด

## กรณีนักเรียนส่งแล้ว แต่หน้าครูไม่แสดง

- หน้าตารางของครูรีเฟรชเองทุก 30 วินาที หรือกดปุ่ม **รีเฟรช** เพื่อดูงานล่าสุดทันที
- ระบบเทียบชื่อห้องแบบไม่สนช่องว่างและเลขไทย เช่น `ม.1/1`, `ม. 1/1`, `ม.๑/๑` ถือเป็นห้องเดียวกัน
- ห้องที่ครูรับผิดชอบให้คั่นด้วย `,` เช่น `ม.1/1,ม.1/2` และชื่อห้องต้องตรงกับคอลัมน์ `class` ในตาราง `data`
- ถ้ายังไม่แสดง ให้รัน `supabase/03_check.sql` ใน SQL Editor ทีละส่วน เพื่อดูว่ามีงานถูกบันทึกหรือไม่ และห้องของครูตรงกับรายชื่อนักเรียนหรือไม่

## ขั้นตอนที่ 3 อัปโหลดขึ้น GitHub Pages

1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ให้ `index.html` อยู่ที่ระดับบนสุดของ repo)
3. ไปที่ **Settings > Pages** เลือก Source = `Deploy from a branch`, Branch = `main`, โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอประมาณ 1-2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## การปรับแต่ง

แก้ไขใน `js/config.js` เช่น ชื่อเว็บ ชื่อโรงเรียน ชื่อวิชา และ Logo ID
(ระบบเรียก `setFaviconUrl` เพื่อตั้งค่า favicon จากโลโก้ Google Drive ให้อัตโนมัติ)

กฎรหัสผ่าน: ต้องมีอย่างน้อย 8 ตัวอักษร มีตัวเลข ตัวอักษรภาษาอังกฤษ และอักขระพิเศษอย่างน้อยอย่างละ 1 ตัว

Admin แก้ไขเบอร์โทรหรือรีเซ็ตรหัสผ่านนักเรียนได้ที่เมนู บัญชีผู้ใช้ > นักเรียน > แก้ไข

นำเข้ารายชื่อนักเรียน: เมนู Admin > รายชื่อนักเรียน > นำเข้า Excel / CSV โดยไฟล์มีหัวคอลัมน์ `ID`, `no`, `name`, `class`
